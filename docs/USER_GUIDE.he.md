# מדריך למשתמש – המאמנת

המאמנת היא אפליקציית צ׳אט בעברית למעקב יומי אחרי תזונה, אימונים ומשקל. מאחוריה עומד Claude.

## שתי דרכים להשתמש

- **דרך claude.ai עם מנוי Claude (Pro/Max): מומלץ.** פותחים את הקישור https://claude.ai/artifact/2Nd8HvkAwi7R9g3jxNQ3Gw כשמחוברים ל-Claude. אין צורך במפתח API ואין תשלום נוסף, והשימוש נספר במכסת המנוי. בהודעה הראשונה מופיעה בקשת אישור לשימוש ב-Claude. הנתונים נשמרים בחשבון שלך ומסתנכרנים בין הטלפון למחשב.
- **כאפליקציה עצמאית (אפשר להתקין כאפליקציה במסך הבית):** https://alonaviram-arch.github.io/fit-coach/. במסך הפרופיל בוחרים:
  - **Gemini · חינם:** מפתח חינמי של Google. ראו „איך מקבלים מפתח Gemini”.
  - **Claude · מפתח API בתשלום:** תשלום לפי שימוש.

  בגרסה העצמאית הנתונים נשמרים רק בטלפון.

## התקנה

**גרסת claude.ai:** פותחים את הקישור בדפדפן בטלפון ומוסיפים למסך הבית מתפריט הדפדפן.

**גרסה עצמאית:**

1. פותחים בטלפון את הקישור: https://alonaviram-arch.github.io/fit-coach/
2. **באייפון (Safari):** כפתור השיתוף ← „הוספה למסך הבית”.
   **באנדרואיד (Chrome):** תפריט ⋮ ← „התקנת אפליקציה”.
3. האפליקציה נפתחת מסמל על מסך הבית, כמו כל אפליקציה אחרת.

## הגדרה ראשונה

במסך **פרופיל** ממלאים:

- **פרטים ומדדי גוף:** גובה, משקל, גיל ומין. אפשר להוסיף גם היקפים (מותניים, ירכיים, חזה, זרוע, ירך) ואחוז שומן.
- **פעילות:** רמת פעילות יומיומית, כמה אימונים בשבוע ואיזה סוג.
- **יעדים:** ירידה, שמירה או עלייה במשקל, משקל יעד, תאריך יעד ויעדי כושר.
- **העדפות תזונה:** מה אוהבים לאכול, והגבלות כמו „ללא גלוטן”.
- **מפתח API של Claude:** ההסבר נמצא בהמשך.

אחרי המילוי האפליקציה מחשבת **יעדים יומיים** של קלוריות, חלבון, פחמימות ושומן. אם יש לכם יעדים מדיאטנית, מסמנים „יעדים מותאמים אישית” ומזינים אותם ידנית.

### איך מקבלים מפתח Gemini (חינם)

1. נכנסים ל-[aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון Google.
2. לוחצים „Create API key” ומעתיקים את המפתח.
3. באפליקציה: פרופיל ← „חיבור ל-AI” ← **Gemini · חינם**, מדביקים את המפתח ושומרים.

טוב לדעת: בשכבה החינמית Google רשאית להשתמש בשיחות לשיפור המוצרים שלה, ויש מגבלת בקשות לדקה וליום. אם מגיעים למגבלה, מחכים דקה (או עד מחר).

### איך מקבלים מפתח API של Claude (בתשלום)

בגרסת claude.ai לא צריך מפתח. בגרסה העצמאית המנוי לא מתחבר, ולכן צריך מפתח API:

1. נכנסים ל-[console.anthropic.com](https://console.anthropic.com) עם אותו מייל של Claude.
2. ב-**Billing** מטעינים קרדיט. התשלום לפי שימוש, בנפרד מהמנוי.
3. ב-**Settings ← API keys** יוצרים מפתח ומדביקים אותו באפליקציה.

המפתח נשמר רק בטלפון שלכם.

## שימוש יומיומי בצ׳אט

פשוט כותבים למאמנת, כמו בצ׳אט רגיל:

| מה כותבים | מה קורה |
|---|---|
| „ארוחת בוקר: 200 גרם יוגורט פרוטאין, סקופ אבקת חלבון, 10 גרם צ׳יה” | המאמנת רושמת, מציגה פירוט לכל רכיב, סיכום לארוחה וכמה נשאר להיום |
| 📷 תמונה של תווית או צלחת | המאמנת קוראת את הערכים מהתמונה או מעריכה אותם, ורושמת |
| „זה היה בורגול מלא” / „לקחתי רק 85 גרם” | הרישום הקיים מתעדכן, בלי כפילות |
| „מה לאכול עכשיו?” / „כמה לשים מכל דבר לצהריים?” / „יש לי בבית עוף ואורז” | המאמנת מציגה 1–3 **כרטיסי הצעה** עם רכיבים, כמויות וערכים שמתאימים למה שנשאר להיום |
| „הקערה הרגילה” / „חצי מהקערה” | נרשם מועדף שמור (אפשר גם עם גודל מנה) |
| „שתיתי 2 כוסות מים” / „ישנתי 6 שעות” / „עשיתי 9,000 צעדים” | נרשם במדדי היום |
| „עשיתי קרוספיט 60 דקות” | האימון נרשם, ואם צריך מקבלים המלצה על פחמימות |
| „שקלתי 79.4” | השקילה נרשמת, ומקבלים הערה על המגמה |
| „סיימתי להיום” / „נחתום” | סיכום יומי מול היעדים ותובנה אחת או שתיים למחר |
| „סיכום שבועי” | ממוצע קלוריות, גירעון, הערכה של ירידה בשומן, אימונים ומגמת משקל |
| „אתמול בערב אכלתי…” | הרישום נכנס לתאריך של אתמול |

מתחת לכל תשובה מופיעות תוויות כמו **✓ נרשם: ארוחת בוקר · 364 קק״ל**, כדי שתראו מה נשמר ביומן.

## כרטיסי הצעה

כששואלים מה לאכול, מקבלים כרטיס לכל הצעה:

- **✓ אכלתי את זה**: נרשם ביומן בלחיצה אחת.
- **התאמה**: משנים גודל מנה (½, ¾, 1, 1¼, 1½), מורידים רכיבים או מחליפים ארוחה, ואז רושמים.
- **☆**: שומרים את ההצעה במועדפים.

הצעה לא נרשמת עד שמאשרים. אם אכלתם משהו קצת אחר, פשוט כתבו בצ׳אט מה אכלתם בפועל.

## מועדפים ⭐

ארוחות שאוכלים הרבה נשמרות כמועדפים ונרשמות בלחיצה אחת:

- **שמירה:** ☆ ליד ארוחה ביומן, ☆ בכרטיס הצעה, או בקשה בצ׳אט („תשמרי את ארוחת הבוקר כמועדף”). המאמנת גם תציע לשמור ארוחה שחוזרת על עצמה.
- **רישום:** כפתור ⭐ ליד שורת ההקלדה בצ׳אט, „⭐ מהמועדפים” ביומן, או לכתוב את השם בצ׳אט.
- **עריכה ומחיקה:** בחלון המועדפים ← „עריכה”.

## יעדים שמתאימים את עצמם 📊

אחרי כ-3 שבועות של רישום ושקילות, האפליקציה מחשבת כמה אנרגיה אתם מוציאים **בפועל**, לפי מה שאכלתם וכמה המשקל השתנה, ולא רק לפי נוסחה:

- אם ההוצאה בפועל שונה מהנוסחה או שהמשקל נתקע, במסך הפרופיל תופיע המלצה ליעדים חדשים עם כפתור „עדכון היעדים לפי הנתונים”.
- אם המשקל נתקע כי הצריכה הממוצעת גבוהה מהיעד, היעד לא יורד. במקום זה תקבלו הסבר, והמאמנת תעזור למצוא מאיפה מגיעות הקלוריות העודפות.
- ההערכה טובה רק כמו הרישום: ימים חסרים או נשנושים שלא נרשמו גורמים לה לצאת נמוכה מדי.

## המסכים

- **💬 צ׳אט:** השיחה עם המאמנת. למעלה יש פסי התקדמות של היום.
- **🍽️ יומן:** מה נאכל בכל יום, לפי ארוחות. אפשר לדפדף בין ימים, למחוק, לשמור למועדפים (☆), להוסיף ידנית או מהמועדפים. יש גם כרטיס מים (לחיצה לכל כוס), צעדים ושינה.
- **🏋️ אימונים:** רישום אימון (סוג, משך, עצימות, קלוריות ותרגילים עם סטים, חזרות ומשקל) וספירה שבועית מול היעד.
- **⚖️ משקל:** שקילה שבועית עם היקפים, גרף מגמה עם קו יעד והתקדמות. מופיעה תזכורת כשעבר שבוע מהשקילה האחרונה.
- **👤 פרופיל:** מדדים, יעדים, העדפות, מפתח API, בחירת מודל וגיבוי.

**טיפ לשקילה:** פעם בשבוע, באותו יום, בבוקר, אחרי שירותים ולפני שאוכלים.

## גיבוי ופרטיות

כל הנתונים נשמרים **רק בטלפון**, בדפדפן. כדאי לגבות מדי פעם: פרופיל ← „ייצוא גיבוי”. כדי לעבור לטלפון חדש, משתמשים ב„ייבוא גיבוי”. המפתח לא נכלל בקובץ הגיבוי.

## בחירת מודל

**בגרסת claude.ai:** „רגיל” (ברירת המחדל), „מתקדם” (הכי מדויק, צורך יותר מהמכסה) או „מהיר”.

**עם Gemini:** „Gemini 3.8 Flash” (מומלץ) או „Gemini 3.5 Flash-Lite” (מהיר יותר, עם מכסה חינמית גדולה יותר).

**עם מפתח Claude:** יש גם „רמת חשיבה”: נמוכה (זול ומהיר), בינונית (ברירת מחדל) או גבוהה. מתחת להגדרה מוצגים השימוש והעלות המשוערת להיום ולשבוע האחרון.

- **Opus 5:** הכי מדויק. זו ברירת המחדל.
- **Sonnet 5:** זול בערך פי 2.5, ועדיין איכותי מאוד.
- **Haiku 4.5:** הכי זול ומהיר.

## חשוב לדעת

המאמנת היא עוזרת מבוססת בינה מלאכותית, לא רופאה ולא דיאטנית קלינית. הערכים התזונתיים הם הערכות. במצבים רפואיים, בהיריון או בחשש להפרעת אכילה, פנו לאיש מקצוע.
